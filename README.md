# Cartographics
Interactive maps to put us in our (respective and collective) place

## Endonym Atlas

[Open the atlas](endonym-atlas/index.html) in a browser, or download [the complete ZIP](endonym-atlas.zip). All application code, map data, pronunciation recordings, source research and assets are bundled in the `endonym-atlas/` folder.

The atlas includes 197 places, 300 selected name variants, native-script and Romanized labels, approximate English pronunciation guides, and 128 audio clips covering 106 places.

See the [atlas README](endonym-atlas/README.md) for usage and local hosting, [research notes](endonym-atlas/research/README.md) for coverage and limitations, and [component licenses and credits](endonym-atlas/LICENSES.md) for reuse terms.
