# A World Wanting Flavor

Open `index.html` directly, or serve this folder with any static web server. All runtime libraries, geometry, and assets are local. No build or internet connection is required. External research links require a connection.

This folder may be distributed on its own; the optional Cartographics navigation link returns to the collection only when a parent index is present.

See [research notes](research/README.md) for source interpretation and limitations and [credits](LICENSES.md) for component licenses.
